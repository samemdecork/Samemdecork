# صمم ديكورك — نسخة الأعمال

هذه النسخة جاهزة للرفع على GitHub Pages أو Vercel.

- `index.html` هو الموقع الرئيسي.
- `images/hero/` صور مختارة للواجهة الرئيسية.
- `images/works/` باقي الأعمال، مضغوطة بصيغة WebP لتسريع الموقع.
- الصور مأخوذة من ملف Hamza hamza.zip الذي أرسلته.
- اسم صاحب الأعمال الظاهر في الموقع: chtaibi hamza.

ارفع المجلد كاملًا كما هو، أو ارفع محتوياته إلى جذر المشروع الحالي.
